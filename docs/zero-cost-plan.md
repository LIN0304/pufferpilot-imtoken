# Zero-Cost Plan

PufferPilot is designed to demo without mainnet gas and without paid APIs.

- Puffer data is read from public demo endpoints with bundled fallback data.
- The AI experience is deterministic local logic plus localStorage preference learning.
- No mainnet transaction is broadcast.
- Holesky testnet support is limited to wallet connection, network switching, and SDK gas estimate.
- No smart contract is deployed.
- No wallet secrets are requested, stored, or transmitted.
- The project can be hosted as a static Vite app on Vercel or GitHub Pages.

The app still displays where gas, approval, or signing would be required in a real wallet flow.
